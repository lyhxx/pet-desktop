# 更新日志

版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`。

- 主版本：不兼容的大改动
- 次版本：新增功能
- 修订号：修复问题

每次发版：更新本文件 → 修改 `DesktopPet.csproj` 的 `<Version>` → 打 tag `vX.Y.Z` 推送。

---

## [1.1.1] - 2026-09-12

### 修复
- 检查更新不再调用 GitHub REST API（未登录限流 60 次/小时，触发 403 后静默失败、总是显示"已是最新"），改为读取 `releases/latest` 的 302 跳转取最新版本号
- 检查失败时明确提示"无法连接更新服务器"，不再假装已是最新

### 优化
- 通知改为**应用内轻提示**（右下角堆叠、几秒淡出、可点击打开链接），不再使用系统托盘气泡

## [1.1.0] - 2026-09-12

新角色企鹅 + 行为与动画系统优化。

### 新增
- 新角色：企鹅（替换原占位小猫），新增 `Pet_Idle` / `Pet_Move` 两套图集
- 走动步态：普通行走 / 小步快走 / 小跑 / 快速移动，按距离与随机选择，速度随之变化
- 转身（`Turn`）与停下（`StopAfterMove`）过渡动画
- 待机时不定时眨眼（`Blink`）
- 集中式剪辑映射 `Core/AnimationClips.cs` + 图集缺失回退链（新图集只需补 `animations.json`）

### 优化
- 行为节奏放缓：每个主动动作结束后进入 2~5 秒休息冷却，待机占比大幅提高，不再动作连播
- 一次性动作剪辑播完自动回到循环的待机，不再停在最后一帧像"卡住"

### 修复
- 出生点与活动范围改用显示器**工作区**（排除任务栏），宠物站在任务栏上沿而非屏幕最底部
- 启动只恢复水平位置，竖直方向回到地面，不再悬在屏幕中间

## [1.0.0] - 2026-09-12

首个版本。

### 新增
- 桌面宠物窗口：无边框、透明、无任务栏按钮、可置顶、可拖动；宠物以外区域鼠标穿透
- 自主行为系统：待机 / 眨眼 / 东张西望 / 伸懒腰 / 整理毛发 / 好奇 / 尾巴动作 / 开心 / 发呆 / 小动作 / 特殊待机，加权随机 + 需求影响
- 状态系统：饱食度、心情、精力、健康；随时间自然变化，永不死亡
- 互动：悬停宠物显示头顶状态 + 右侧弧形菜单；喂食（小鱼干 / 猫粮 / 牛奶）、摸摸、装扮、设置、隐藏
- 独立粒子效果层：爱心、星星、汗滴、睡眠气泡，与状态机解耦
- 装扮：帽子 / 眼镜 / 围巾，本地选择即时生效
- 系统托盘：显示隐藏、设置、重新定位、检查更新、退出
- 本地 JSON 存档 + 离线时间结算（封顶 72 小时）
- 开机启动（HKCU Run）、音效（运行时合成）
- 精灵图切图工具 SpriteSlicer（缩放 / 清噪 / 清格线 / 锚点归一化 / 生成 ico）
- GitHub Actions：push/PR 自动编译；打 tag 自动发布绿色版 zip 与 Inno Setup 安装包
- 检查更新：从 GitHub Releases 检查新版本并托盘提示
