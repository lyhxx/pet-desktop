# 更新日志

版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`。

- 主版本：不兼容的大改动
- 次版本：新增功能
- 修订号：修复问题

每次发版：更新本文件 → 修改 `DesktopPet.csproj` 的 `<Version>` → 打 tag `vX.Y.Z` 推送。

---

## [1.0.0] - 2026-09-12

首个版本。

### 新增
- 桌面宠物窗口：无边框、透明、无任务栏按钮、可置顶、可拖动；宠物以外区域鼠标穿透
- 自主行为系统：待机 / 眨眼 / 东张西望 / 伸懒腰 / 整理毛发 / 好奇 / 尾巴动作 / 开心 / 发呆 / 小动作 / 特殊待机，加权随机 + 需求影响
- 状态系统：饱食度、心情、精力、健康；随时间自然变化，永不死亡
- 互动：悬停宠物显示头顶状态 + 右侧弧形菜单；喂食（小鱼干 / 猫粮 / 牛奶）、摸摸、装扮、设置、隐藏
- 独立粒子效果层：爱心、星星、汗滴、睡眠气泡，与状态机解耦
- 装扮：帽子 / 眼镜 / 围巾，本地选择即时生效
- 系统托盘：显示隐藏、设置、重新定位、检查更新、退出
- 本地 JSON 存档 + 离线时间结算（封顶 72 小时）
- 开机启动（HKCU Run）、音效（运行时合成）
- 精灵图切图工具 SpriteSlicer（缩放 / 清噪 / 清格线 / 锚点归一化 / 生成 ico）
- GitHub Actions：push/PR 自动编译；打 tag 自动发布绿色版 zip 与 Inno Setup 安装包
- 检查更新：从 GitHub Releases 检查新版本并托盘提示
